# সিনেখোঁজ (CineKhoj)

বাংলাদেশ থেকে কোন সিনেমা, নাটক আর ওয়েব সিরিজ কোথায় বৈধভাবে দেখা যায়, তার বাংলা গাইড। সাইটটা [Astro](https://astro.build) দিয়ে বানানো স্ট্যাটিক সাইট।

## ফোল্ডারগুলো

| ফোল্ডার | কী আছে |
|---|---|
| `src/content/titles/` | প্রতিটা সিনেমা, নাটক বা সিরিজের একটা করে `.md` ফাইল |
| `src/content/platforms/` | প্রতিটা ওটিটি প্ল্যাটফর্মের একটা করে `.md` ফাইল |
| `src/pages/` | পাতার নকশা (সাধারণত বদলাতে হবে না) |
| `public/` | ছবি, ফেভিকন, robots.txt |

## নতুন সিনেমা, নাটক বা সিরিজ যোগ করা

1. `src/content/titles/toofan.md` ফাইলটা কপি করে নতুন নাম দিন, যেমন `src/content/titles/priyotoma.md`। ফাইলের নামই হবে পাতার ঠিকানা: `/movie/priyotoma/`। নাম ইংরেজি ছোট হাতের অক্ষরে, শব্দের মাঝে `-` দিয়ে লিখবেন।
2. উপরের `---` চিহ্নের ভেতরের তথ্যগুলো বদলান:
   - `type`: `movie` (সিনেমা), `series` (ওয়েব সিরিজ) বা `natok` (নাটক)
   - `summary`: গুগলে যে বর্ণনা দেখাবে, ১-২ বাক্যে সরাসরি উত্তর
   - `availability`: **শুধু যেখানে নিজে অ্যাপে খুঁজে পেয়েছেন।** `platform`-এ প্ল্যাটফর্ম ফাইলের নাম লিখবেন, যেমন `chorki`
   - `checkedPlatforms`: যেসব জায়গায় খুঁজেছেন, পাওয়া যাক বা না যাক
   - `lastVerified`: অ্যাপে যাচাইয়ের তারিখ, যেমন `2026-11-12`। না দিলে পাতায় "এখনো যাচাই হয়নি" দেখাবে
   - যে তথ্য জানা নেই সেই লাইন মুছে দিন, কিছু ভাঙবে না
3. নিচের `---`-এর পরে কাহিনি সংক্ষেপ আর নিজের মতামত লিখুন।
4. লেখায় কমা থাকলে পুরো লেখাটা `"..."` দিয়ে ঘিরে দিন, যেমন `role: "আকরাম, সিআইডি"`। না দিলে কমার পরের অংশ হারিয়ে যায়।
5. খসড়া হলে `draft: true` লিখে রাখুন, সাইটে দেখাবে না।

## নতুন প্ল্যাটফর্ম যোগ করা

`src/content/platforms/chorki.md` কপি করে নতুন নাম দিন (যেমন `bongo.md`) আর তথ্য বদলান। অ্যাফিলিয়েট লিংক পেলে `affiliateUrl:` লাইনে দেবেন। তখন সব বোতাম নিজে থেকেই সেই লিংকে যাবে।

## GitHub-এর ওয়েবসাইট থেকে সরাসরি সম্পাদনা

কম্পিউটারে কিছু ইনস্টল না করেও কাজ করা যায়। GitHub-এ ফাইল খুলে পেনসিল আইকন চেপে সম্পাদনা করুন, তারপর **Commit changes** চাপুন। নতুন ফাইলের জন্য ফোল্ডারে গিয়ে **Add file → Create new file**।

## সাইট লাইভ করা (Cloudflare Pages, ফ্রি)

1. [Cloudflare](https://dash.cloudflare.com)-এ অ্যাকাউন্ট খুলুন
2. Workers & Pages → Create → Pages → Connect to Git → এই রিপো বেছে নিন
3. Build command: `npm run build`, Build output directory: `dist`
4. Save and Deploy। এরপর রিপোতে প্রতিটা পরিবর্তন নিজে থেকেই লাইভ হবে
5. ডোমেইন কেনার পর Custom domains থেকে যুক্ত করুন, আর `astro.config.mjs` ও `public/robots.txt`-এ ডোমেইনের নাম মিলিয়ে নিন

## অ্যাডসেন্স চালু করা

অনুমোদন পাওয়ার পর Cloudflare Pages-এর Settings → Environment variables-এ যোগ করুন:

```
PUBLIC_ADSENSE_CLIENT=ca-pub-আপনার-আইডি
```

আর `public/ads.txt` ফাইল বানিয়ে গুগলের দেওয়া লাইনটা লিখুন। তার আগে পাতায় বিজ্ঞাপনের জায়গায় শুধু খালি বক্স দেখাবে।

## নিজের কম্পিউটারে চালানো (ঐচ্ছিক)

[Node.js](https://nodejs.org) ইনস্টল করে:

```
npm install
npm run dev
```

তারপর ব্রাউজারে `http://localhost:4321` খুলুন।
